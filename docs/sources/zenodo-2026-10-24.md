Also read on those pages, not used as a rule here: higher quotas "can be requested" (S1, up to
200GB per the Manage files page); Zenodo stores an MD5 checksum of each file (S1, "Fixity and
authenticity"); minor file corrections are allowed within 30 days of publication (Manage files).
Refute's own SHA-256 manifest stays the reference for a file's identity.
