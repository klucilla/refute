## Process deviation (Claude): CPU affinity

The first run of the search ran for about 5 s on all logical processors, because
PowerShell 5.1 rejected the affinity mask (`[IntPtr]0xFFFFFF00` became an invalid value:
"Parâmetro incorreto"; the process kept affinity 4294967295). The output of that run is in
`.cache/gate/claude/search/tess_eb_search_gate_noaffinity.txt`. It was repeated with
`start /affinity FFFFFF00` and the output was identical, except for the exit-code line that
only the second one writes (`.cache/gate/claude/search/tess_eb_search_gate_affinity.txt`).
The other loads (full listing, ruff, pytest) ran on logical processors 8-31.
