  OEbox>3". Todas literais. A frase "the noise over the corresponding transits"

- **O que os trechos não decidem está dito** (correction-2.md:107-118): os trechos dão a equação

  também não definem σ_bin, σ_bin,xpt nem N_tr; a correção só reivindica a "forma" de K25, o que

- **σ_r²:** com `Var(μ_k) = s²/W_k + σ_r²`, `E[Q₀] = s²(M−1) + σ_r²(B − ΣW_k²/B)` e

- **Invariância de escala:** multiplicar todos os σ por uma constante não muda `s²/W_par` nem
  `σ_r²`. Logo s² corrige um erro comum de escala dos σ, mas não um erro que difira entre
  setores ou paridades (ver N6).
- **σ iguais** (correction-2.md:181-186): branco = variância amostral / n_par; vermelho com
  contagens iguais m = variância amostral das médias dos bins menos variância amostral da

## 4. Achados bloqueantes

### B1. O termo vermelho `σ_r²/N_par` ignora os pesos das épocas e fica anticonservador com ruído correlacionado e pesos desiguais

**Evidência.**
- correction-2.md:152-153: `σ_par² = s²/W_par + σ_r²/N_par`, com N_par = número de épocas.
- correction-2.md:157-158: "The red contribution divided by epoch count is a modelling choice."
  A escolha está marcada, mas a consequência não está declarada.
- correction-2.md:198-199 (T2, T6): o ponto preciso faz W_odd crescer, o termo branco some, e a
  média ponderada da paridade passa a ser, na prática, **uma** época. O termo vermelho continua
  dividido por todas as épocas.
- specification.md:124-126: o limiar 3 só é regra de três erros padrão "provided the noise is
  calibrated".

**A matemática.** A profundidade da paridade é a média ponderada `Σ_e W_par,e·x_e / W_par`. Com
um desvio vermelho independente por época, de variância σ_r² (o modelo implícito na Eq. (2) de
K25), a variância vermelha dessa média é `σ_r² · Σ_e W_par,e² / W_par²`. Isso só vale
`σ_r²/N_par` quando as épocas têm o mesmo peso; em qualquer outro caso é maior. A correção
trata o termo branco com os pesos e o vermelho sem eles, e os dois deixam de ser coerentes
exatamente nas famílias que a motivam (setor ruidoso, ponto preciso).

**Cheque exploratório meu (não é resultado do projeto).** Simulação sintética nula (profundidades
iguais, sem trânsito), meu próprio oráculo do texto da seção 4, `numpy` 2.5.3, `python3 -I`.
Semente de cada execução: `20261126 + índice da família + int(red·1e6)`. 2.000 curvas por
célula; P = 3 d, T = 0,1 d, 14 cadências por bin, 27 d, 4 épocas ímpares e 5 pares; σ branco
1e-3; ruído vermelho = um desvio gaussiano constante por bloco de largura T, alinhado aos bins.
Famílias minhas (as definições de S9.5, T2, T6 do projeto não estão no pacote): U (σ iguais),
S (segunda metade com σ×9,5), S3 (dois terços finais com σ×9,5), Pp (paridade ímpar com σ×9,5),

## 6. Código do cheque exploratório (B1)

Exploratório, meu, sem relação com o código do projeto. Executado com `python3 -I`, entrada
padrão, sem arquivo criado.

```python
# EXPLORATORY reviewer simulation; not a project result. Seed base 20261126.
import numpy as np, math
P, T, DT, SPAN = 3.0, 0.1, 0.1/14, 27.0   # 14 cadences per T-bin
t = (np.arange(int(round(SPAN/DT))) + 0.5) * DT
tb = t[0]
t0 = tb - 0.5*DT + 10*T + 0.5*T           # transit windows coincide with bins
k = np.floor((t - t0)/P + 0.5).astype(int)
intr = np.abs(t - (t0 + k*P)) <= T/2
d = np.abs(np.mod(t - t0 + P/2, P) - P/2)
base = d > T
binid = np.floor((t - tb)/T).astype(int)
blk = np.floor((t - (tb-0.5*DT))/T + 1e-9).astype(int)  # red-noise blocks of width T
def f1(f, sig, kish=False):
    w = 1/sig**2
    wb, fb, bb = w[base], f[base], binid[base]
    mb = np.sum(wb*fb)/np.sum(wb); nb = wb.size
    s2 = np.sum(wb*(fb-mb)**2)/(nb-1)
    ids, inv, cnt = np.unique(bb, return_inverse=True, return_counts=True)
    Wk = np.bincount(inv, wb); mu = np.bincount(inv, wb*fb)/Wk
    keep = cnt >= 2; Wk, mu = Wk[keep], mu[keep]; M = Wk.size
    B = Wk.sum(); mubar = np.sum(Wk*mu)/B; Q0 = np.sum(Wk*(mu-mubar)**2)
    pre = np.concatenate(([0.0], np.cumsum(Wk)[:-1])); C = 2*np.sum(Wk*(pre/B))
    sr2 = max(0.0, (Q0 - s2*(M-1))/C)
    out = []
    for par in (0, 1):
        sel = intr & (np.mod(k, 2) == par)
        Wp = w[sel].sum(); m = np.sum(w[sel]*f[sel])/Wp
        ep, einv = np.unique(k[sel], return_inverse=True)
        if kish:
            We = np.bincount(einv, w[sel]); red = sr2*np.sum(We**2)/Wp**2
        else:
            red = sr2/ep.size
        out.append((m, s2/Wp + red))
    return abs(out[0][0]-out[1][0])/math.sqrt(out[0][1]+out[1][1]), s2, sr2
SW = 1e-3
def family(name):
    sig = np.full(t.size, SW)
    if name == "S": sig[t > SPAN/2] *= 9.5          # noisy second half
    if name == "Pp": sig[np.mod(k,2)==1] *= 9.5      # noisy odd parity
    if name == "T":                                   # one precise in-transit cadence, odd parity
        i = np.where(intr & (k == 1))[0][7]; sig[i] = SW/100
    if name == "S3": sig[t > SPAN/3] *= 9.5
    return sig
def run(name, red, n, seed):
    rng = np.random.default_rng(seed); sig = family(name)
    cnt = [0, 0]; s2s = []; srs = []
    for _ in range(n):
        f = 1 + rng.normal(0, 1, t.size)*sig
        if red > 0: f = f + (rng.normal(0, red, blk.max()+1))[blk]
        for j, ksh in enumerate((False, True)):
            oe, s2, sr2 = f1(f, sig, ksh); cnt[j] += oe > 3
        s2s.append(s2); srs.append(math.sqrt(sr2))
    return cnt, float(np.mean(s2s)), float(np.mean(srs))
```
