## Verdict: **REFUTED**

Two acceptance-critical implementation differences remain: A0 treats short autocorrelation series as independent, and WP3 (d) uses an unweighted amplitude estimator despite requiring weighted least squares. The review was read-only; I did not run the acceptance suite, so I make no claim that the calibration rows pass.

## Objections

1. **High, A0’s `n_eff` can ignore observed dependence.** The acceptance gives the `n_eff` formula without a 20-pair cutoff for the per-stratum autocorrelation used in it ([acceptance](C:/Projetos/refute/docs/plans/v0.5.1-acceptance.md):119–123). But `lag_correlation` returns `None` below `MIN_PAIRS` (20), and `effective_count` treats a missing correlation as zero ([a0.py](C:/Projetos/refute/src/refute/packs/tess/a0.py):164–180). `stratum_error` uses this same function for `r_k` ([a0.py](C:/Projetos/refute/src/refute/packs/tess/a0.py):183–194). That can inflate `n_eff`, admit an event, and understate its corrected error. **Change required:** estimate per-stratum autocorrelation from the available within-segment pairs according to the acceptance rule; reserve the 20-pair minimum for the cross-stratum group correlations that explicitly require it.

2. **High, WP3 (d) is not weighted least squares.** The acceptance requires a weighted least-squares trapezoid amplitude ([acceptance](C:/Projetos/refute/docs/plans/v0.5.1-acceptance.md):359–362). `matched_measure` computes the unweighted amplitude `sum(s * (1-f)) / sum(s²)` and unweighted information ([a0.py](C:/Projetos/refute/src/refute/packs/tess/a0.py):386–406). The per-event model error is then `robust_sigma / sqrt(info)` ([battery_v51.py](C:/Projetos/refute/src/refute/packs/tess/battery_v51.py):309–331), also assuming uniform cadence noise. **Change required:** apply the cadence weights in the real-event and pseudo-event estimators, and derive the model error from the same weighted information.

3. **Medium, WP3 (d) omits the required exclusion reason on inconclusive results.** A0 requires the reason “phase-0.5 windows excluded: a secondary detected” when exclusion leaves a statistic outside its data or estimability domain ([acceptance](C:/Projetos/refute/docs/plans/v0.5.1-acceptance.md):100–109). WP3 (d) receives the exclusion flag, but its inconclusive branches return generic messages for too few measured transits or no calibrated error ([pipeline.py](C:/Projetos/refute/src/refute/packs/tess/pipeline.py):371–375; [battery_v51.py](C:/Projetos/refute/src/refute/packs/tess/battery_v51.py):335–362). The flag is recorded in metrics only on the ordinary result path. **Change required:** include the required reason in both inconclusive messages when the exclusion applies, preserving their `not_enough_data` and `insufficient_sensitivity` classes.

4. **Low, shortcut bootstrap can use fewer than 200 replicates.** A0 specifies 200 bootstrap replicates for the equivalence intervals ([acceptance](C:/Projetos/refute/docs/plans/v0.5.1-acceptance.md):147–158). The implementation skips replicates where either correlation cannot be estimated and accepts as few as 100 before computing the interval ([a0.py](C:/Projetos/refute/src/refute/packs/tess/a0.py):238–260). **Change required:** require all 200 usable replicates for each term, or explicitly amend the acceptance rule before relying on shorter intervals.
