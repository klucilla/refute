# External sources of stage 1 (X0c, X2, X3)

The maintainer's decision of 2026-10-21, item 6: external research is allowed where it helps X0c,
X2 and X3, each external fact with its URL, the date it was read and a short literal excerpt kept
here, so it can be checked later even if the page changes. Only the abstract pages were read; a
statement that rests on more than the abstract is not made.

**Revised on 2026-10-21 (the maintainer's decision after X0c and X1b, item 5):** each Kepler or TESS
reference names the procedure and the data it used, as far as its abstract states them; a general
precedent **validates no gate, threshold or rule here**. These sources are context for why a
question is asked, never evidence that Refute's answer to it is right; every claim about Refute's
engine rests on its own declared experiments.
