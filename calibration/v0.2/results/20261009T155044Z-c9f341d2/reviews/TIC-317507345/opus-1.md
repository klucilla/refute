## Summary
The dossier for TIC 317507345 (TOI-1615.01, a known false positive) is intact. Its `REFUTED` verdict is correct as computed, but it rests only on a lookup in the TESS-EB catalog. The signal-analysis tests did not refute the target, even though the data show a V-shaped eclipse and a secondary eclipse too deep for a planet. Under the claim's own rule (`flag_excluded_tests: [eb_catalog]`), this target would count as WEAKENED, not "flagged", and the report does not say so.

## Checks with no objection
- **Integrity.** `uv run --frozen refute check-dossier <dossier>` returned "OK: manifest intact". `integrity.json` has status PASS: locked and current claim SHA-256 are both c9f341d2…, code SHA-256 is 2cd8b5c1… for both, and `changed_files` is empty. `claim.lock.json` is byte-identical to `git show cc9d104:calibration/v0.2/self_claim.lock.json` (98f37ef0…). `claim.yaml` is byte-identical to the committed claim (80a48356…). All 6 attachment SHA-256 values match the lock. Between the lock commit e176ac3 and the run commit cc9d104, `git diff --stat` shows only `calibration/v0.2/` lock and log files, no code.
- **Target.** TIC coordinates in `data/manifest.json` (RA 351.17447, Dec 77.62710) match ExoFOP (23:24:41.93, +77:37:37.61). Tmag is 9.687 in both. TIC R = 1.511 and M = 1.69 match ExoFOP's 1.51 and 1.69.
- **Product.** SPOC 120-s PDCSAP, default quality bitmask. 7 light curves and 7 TPFs (sectors 18, 52, 58, 59, 73, 78, 79), with per-file SHA-256 and MAST URIs; this matches the MAST record in `targets.yaml`. ExoFOP sectors 19, 24 and 25 have no SPOC 2-min products. That is consistent with the data rule and does not invalidate any test.
- **Signal.** Found period 3.9401763 d against published 3.9401791 d gives relative error 7.0e-7, so it is recovered at P, not an alias. The global ephemeris predicts the published epoch to within about 1.4 min. SNR is 445.
- **odd_even.** Depths differ by 0.28 sigma (17 odd, 18 even). This is consistent with a primary/secondary pair at P = 3.94 d, not a 2P binary with equal eclipses.
- **aperture_depth.** The large-aperture depth is shallower (ratio 0.94, −3.8 sigma), as expected for an on-target source.
- **nearby_contamination.** The only TIC source within 21 arcsec (TIC 317507346, Tmag 17.14) would need an eclipse depth above 100%. Median CROWDSAP is 0.98.
- **systematics.** SAP depth 11,867 ppm against an expected 11,860 ppm. No transits near momentum dumps. Background rise is −0.23 sigma.
- **period_alias.** A box on top of a sinusoid is favored by ΔBIC 85,162, and the period is not near the listed systematic periods.
- **Blind holdout.** I checked all 176 access-log entries:
  - Every entry lies inside the hidden year's sector spans, and none overlaps a training sector.
  - Only registered transit and control windows and their baseline bands were read; `HiddenYear` enforces this in the code at cc9d104.
  - Transit windows are at most 1.11 times the train box duration (about 1.58 h), narrower than the real eclipse (about 2.1 h; `plots/holdout_2023.png`).
  - The baseline bands start at 1.15 h, outside the eclipse.
  - Predicted centers fall within 0.7 min of the global ephemeris.
  - Hidden-year SNR is 25–69 in all four years, and depths agree with training within 0.75 sigma.
- **Text.** `report.md` carries the scope note and the "nothing here is a confirmed discovery" statement. It calls the target a false positive with verdict `REFUTED` and does not claim a discovery.
